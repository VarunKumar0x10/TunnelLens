TunnelLens API reference

A single-user local API for the Tier B experimental MVP. Download the OpenAPI schema. This page uses no external scripts or styles.

Uploaded bytes are removed after analysis. Reports contain metadata. Bind to localhost. Limit: 25 MB, 100,000 packets, 20 seconds. One analysis at a time.

Endpoints

Method / PathBehavior
GET /api/healthReadiness, limits and model availability.
GET /api/modelModel metadata, feature importance and synthetic-only evaluation; no real-application accuracy claim.
GET /api/samplesSeven synthetic protocol and encrypted-workload demo captures with provenance.
GET /api/samples/{id}/captureDownload a sample PCAP.
POST /api/samples/{id}/analyzeAnalyze a selected scenario through the parser and experimental classifier.
POST /api/analyzeMultipart form field file containing a PCAP/PCAPNG. Returns the report.
GET /api/analyses/{id}Stored report JSON; generated 32-character lowercase hexadecimal ID.
GET /api/analyses/{id}/report.jsonDownload report JSON as an attachment.
GET /report/{id}Printable executive and technical HTML report with evidence.

Errors

400: invalid capture or unsupported format. 404: missing report/sample. 408: analysis timeout. 413: upload too large. 429: analyzer busy. 500: worker failure.

Report contract

The report includes input hash/provenance, input summary, IKE sessions, directional ESP streams, packet evidence, findings, assessment coverage, window-level experimental inference and abstention, and limitations.

Unknown values remain null. IKE transforms do not populate ESP/Child-SA cipher fields. The locally trained Random Forest is validated only on generated ESP workloads. Scores are uncalibrated; unrecognized uploads retain UNKNOWN as their accepted result while showing experimental candidates. Risk is a project score (0 lower observed risk, 100 higher observed risk), not a compliance certification.
